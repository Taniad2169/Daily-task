How to use the ADA Generator

  1. Fill in the client on the left: business name, website, industry, platform, state and the email/phone people can use for accessibility help. Pick ADA toolbar only or ADA + cookie banner (what they paid for).
  2. Install code tab: copy the code and paste it on their site using the steps for their platform (SiteSwan, Wix, GoDaddy…). Open the live site and check the ♿ button works.
  3. Approve the website in your widget dashboard (button on the Install tab) so it keeps running, and send the signed-agreement link if they haven't signed.
  4. Checklist tab: mark each item honestly. Only mark Done by WebSwan what you actually did. Everything else stays Needs review or Recommended; those become upsells (alt text, forms, captions, monthly review).
  5. Statement tab: download the statement page or copy it, and publish it on their site at the address you chose (for example /accessibility). Ask the client to have their attorney look it over.
  6. Client report tab: press Save as PDF, then Email draft to client and attach the PDF.
  7. Save client so you can open them again next month for the review.
Never say "fully ADA compliant" or "guaranteed." Say: "We installed an accessibility toolbar and statement and reviewed your site; here's what's done and what still needs work." The state notes on the Checklist and report tell the client why it matters in their state.
