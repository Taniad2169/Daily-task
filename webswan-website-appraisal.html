WebSwan Website Appraisal Lab

Private tool · Paste a page source, add what you know about traffic and revenue, and get a buyer-style valuation, an issue report, and a fix vs. redesign quote.

1The website

Open the site, press Ctrl+U (Mac: ⌥⌘U) to view the source, select all, copy, and paste it below. Or upload a saved .html / .txt file.

If blank, it's read from the page's canonical tag.

2Live speed & quality test (optional, recommended)

Runs Google PageSpeed Insights (Lighthouse) on the live URL for mobile and desktop: real load speed, Core Web Vitals, accessibility, SEO and best-practice scores. Only the URL is sent to Google. Takes about 30–60 seconds.

3Traffic, analytics & money (what an appraiser asks for)

Pull these from the owner's Google Analytics 4 / Search Console / Stripe / Shopify, or estimates from Similarweb or Semrush. Leave blank what you don't know — the report widens the value range and lists it as a data gap.
